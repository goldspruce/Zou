An implementation of the **Paper2Agent** framework (*Jiacheng Miao, Jonathan K. Pritchard, James Zou et al., Nature, 2026*) applied to the draft manuscript:

> **The Quick Initial Doublet: A Common Mechanism Across Neural Subsystems**  
> *Manuscript file: `Oct QID Review of July 28 2026.pdf`*

---

## 🔬 Overview & Background

Traditional scientific papers are static PDFs. Even when they contain mathematical derivations or computational modeling, readers must manually read, transcribe, and debug code to verify claims or explore alternative scenarios.

**Paper2Agent** transforms a research paper into an active, runnable AI agent packaged as a **Model Context Protocol (MCP)** server. For this draft paper, which had no pre-existing external GitHub repository, the computational biophysics engine embedded inside **Appendix D** was extracted, verified, and packaged into a modular scientific library and interactive agent.

```
Oct QID Review of July 28 2026.pdf
                  │
                  ▼
   [Phase 1: Code & Model Synthesis]
     ├── electrophysiology.py (AMPA EPSP decay, temporal summation, Vm priming)
     ├── kinematics.py        (Hill Ca2+ cooperativity, ballistic jump ODE)
     ├── aging.py             (Lifespan QID underclocking & dynapenia)
     └── knowledge_base.py    (4 neural subsystems & motor control hierarchy)
                  │
                  ▼
   [Phase 2: Paper2Agent Verification Suite]
     └── verify_benchmarks.py (Validated <=3% against Appendix D tables)
                  │
                  ▼
   [Phase 3: Deployment & Interfaces]
     ├── mcp_server.py        (JSON-RPC 2.0 stdio MCP Server for AI clients)
     ├── run_agent.py         (Interactive Terminal Virtual Co-Author)
     └── web_dashboard.py     (Zero-dependency live browser visualizer)
```

## ⚡ Quick Start

### 1. Run the Automated Verification Suite
Verify all computational outputs against the paper's exact numerical tables (pp. 7–21):
```bash
python3 verify_benchmarks.py
```
*Output: 100% PASS across all electrophysiological and kinematic benchmark regimes (error < 1.0%).*

---

### 2. Launch the Interactive Co-Author CLI
Chat with the paper's knowledge base and run on-the-fly simulations:
```bash
python3 run_agent.py
```
**Example commands inside the CLI:**
* `jump 90` — Simulates the kinematic drop-off of a 90 Hz doublet.
* `epsp 150` — Computes UMN temporal summation and LMN membrane potential deficit.
* `age 70 1` — Evaluates a 70-year-old masters athlete profile.
* `spikes 80` — Prints the millisecond-by-millisecond spike event schedule.
* `subsystems` — Summarizes the 4 neural subsystems (LMN, UMN, Octopus cells, PV+ interneurons).
* `benchmarks` — Displays the complete replicated matrix from Appendix D.

---

### 3. Open the Interactive Visual Lab (Web Dashboard)
Start the local server and open [http://localhost:8080](http://localhost:8080) in your browser:
```bash
python3 web_dashboard.py
```
*Features live interactive sliders for QID Firing Rate (25–110 Hz), EPSP decay time constant $\tau$, and Chronological Age (20–85 years) with dynamic charts.*

---

### 4. Connect to Claude Desktop / Cursor / Antigravity via MCP
Add the following snippet to your `claude_desktop_config.json`:
```json
{
  "mcpServers": {
    "qid-paper2agent": {
      "command": "python3",
      "args": [
        "/Users/rhl/Documents/Zou/mcp_server.py"

  }
}
```

Once connected, any MCP-enabled AI can directly invoke tools:
* `simulate_vertical_jump(frequency_hz)`
* `calculate_epsp_summation(frequency_hz, tau_ms)`
* `predict_aging_trajectory(age_years, is_active_athlete)`
* `get_spike_train_schedule(frequency_hz)`
* `query_paper_knowledge(query)`

## 🧠 The 4 Neural Subsystems Modeled

1. **Lower Motor Neurons (LMN) / Fast-Twitch Muscle Units (100 Hz $\to$ 25 Hz)**:
   * Triggers the phase transition from relaxed/eccentric state to concentric muscle tetanus.
   * Exploits troponin C Ca2+ cooperativity ($n_H \approx 2.22$) to deliver $445\text{ m/s}^3$ Jerk in the 50 ms ignition window before dialing back to 25 Hz to prevent metabolic exhaust.
2. **Upper Motor Neurons (UMN) / M1 Betz Cells (200 Hz $\to$ singlets)**:
   * Metaphorical "engine start": primes quiescent LMNs from $-65\text{ mV}$ resting potential to $-55\text{ mV}$ threshold.
3. **Auditory Octopus Cells / Ventral Cochlear Nucleus (300 Hz)**:
   * "Knock-knock" double tap coincidence detector yielding sub-millisecond temporal resolution for Interaural Time Difference (ITD) sound localization.
4. **Cortical PV+ Interneurons (300 Hz $\to$ silence)**:
   * Clockwork pendulum escapement that exerts a synchronized inhibitory clamp, pacing pyramidal neurons into 40 Hz gamma oscillations for cognitive binding.
